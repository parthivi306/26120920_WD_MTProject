1. Project Objective & Design Philosophy

The objective of this assignment was to transform a plain semantic HTML resume into a visually engaging, professional, and responsive personal website. The design was tailored to reflect a strategic personal brand focused on Growth, Strategic Partnerships, and Digital Business. The goal was to master key CSS concepts—typography hierarchy, semantic color theory, multi-dimensional layouts (Flexbox and Grid), position manipulation, and responsive accessibility—ensuring both aesthetic appeal and optimal user experience.

2. Key CSS Techniques & Improvements Made

A. Custom Typography Pairing & Visual Hierarchy

Integrated Google Fonts to create an editorial pairing: Playfair Display (transitional serif) for primary and secondary headings, paired with DM Sans (geometric sans-serif) for body text and navigation. Fluid typography was achieved using the CSS clamp() function (clamp(2.8rem, 7vw, 5rem)) for the main Hero headline, allowing text to seamlessly scale across viewports without rigid media queries.

B. Centralized Design Tokens via CSS Variables (:root)

Established a reusable, high-contrast palette using CSS Custom Properties in the root pseudo-class:

  • --cream (#FFFDF9): Warm, inviting background color replacing clinical pure white.
  • --burgundy (#6E1F2E): Authoritative primary brand accent applied to headings, cards, and the contact banner.
  • --terracotta (#EA580C): Energetic secondary accent for CTA buttons, underlines, and interactive hover states.
  • --ink (#111827) & --muted (#5C6472): Optimized body text colors passing strict WCAG AA contrast standards.

C. Advanced Display & Positioning Architectures

  • Sticky Navigation Header: Configured position: sticky; top: 0; z-index: 10; combined with backdrop-filter: blur(6px) to create a modern translucent glassmorphism bar that stays pinned during scrolling.
  • Flexbox Layouts: Utilized display: flex with justify-content: space-between and align-items: center for the header, alongside wrapping pill tags (.chips) with gap properties.
  • CSS Grid Layouts: Implemented a 2-column grid (grid-template-columns: 260px 1fr) for the About section to seamlessly pair a cropped portrait with narrative bio paragraphs, and auto-fit grids (minmax(min(100%, 300px), 1fr)) for project and certification cards.

3. Section-by-Section Design Decisions

Section Design Implementation & CSS Logic
Sticky Header Horizontal flexbox alignment with flex-wrap: nowrap on desktop. Connected to smooth-scrolling page anchors using html { scroll-behavior: smooth; scroll-padding-top: 80px; }.
Hero Section Two-column responsive grid featuring an impactful headline, terracotta accent rule (.rule), 2 call-to-action buttons (See my work and View Resume ↗), and a styled "Quick Facts" card.
About Me Incorporated a formal portrait headshot with object-fit: cover, object-position: center 20%, subtle drop-shadow, and rounded corners (border-radius: 12px) alongside narrative paragraphs.
Experience & Projects Role timelines with a burgundy vertical accent line (border-left: 3px solid var(--burgundy)). Projects formatted into interactive cards with hover lift (transform: translateY(-4px)) and depth shadow.
Education & Leadership Structured tabular grid (140px 1fr) for degrees and timelines. Leadership highlights NCC achievements and Model United Nations positions.
Skills Divided into two organized categories: Digital Tools (Excel, Office, Canva, Generative AI) and high-impact Soft Skills (Relationship Building & Outreach, Negotiation, Problem Solving) displayed as pill badges.
Certifications Showcases the ongoing McKinsey Forward Program using a custom outlined status badge (.tag.wait) alongside received NCC camp certifications.
Contact & Footer Full-width inverted burgundy container featuring email, location, and an interactive Connect on LinkedIn ↗ button linked directly to my professional profile.

4. Responsive Design & Accessibility (WCAG)

Mobile Adaptability & Accessibility Considerations:
  • Small Viewport Protection: Adopted modern min(100%, 300px) within card grids to prevent horizontal scrolling and page overflow on narrow screens (e.g., iPhone SE at 320px).
  • Media Queries: Breakpoints at 880px and 820px gracefully collapse multi-column sections into vertical single-column mobile flows.
  • Focus & Motion: Added distinct keyboard focus rings via :focus-visible and motion-reduction support via @media (prefers-reduced-motion: reduce).

5. Conclusion

This project successfully elevated a basic resume into a modern web portfolio. By leveraging CSS Grid, Flexbox, custom design tokens, and thoughtful typography, the site achieves high visual appeal, intuitive navigation, and responsive durability across modern devices.
